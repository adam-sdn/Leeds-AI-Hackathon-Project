# Refresh Loading Screen

Use the cube-tile loader when the app refreshes translated copy after a language change. The loader should sit on top of the existing dark glass interface, keep a blue theme, and clearly indicate that the selected language is being loaded.

The original component was supplied as `loader-3.tsx`. This project is a Vite React app, so the loader is implemented as a plain React/TypeScript component with CSS in `App.css` rather than shadcn/Tailwind-specific classes.
