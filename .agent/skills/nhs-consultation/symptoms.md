# NHS Symptoms A to Z

Use this file as a symptom reference for Kashf.ai NHS-style wording and triage support.

When accessed:
- Treat this as an index, not the full clinical guidance.
- If a symptom item has an NHS hyperlink, open/follow that NHS link to gather more detail before writing final patient-facing guidance.
- Use only NHS-style, non-diagnostic wording.
- Keep Kashf.ai safety rules: this is not a medical diagnosis, red flags need urgent escalation, and facial scan data is only visible wellness context.
- Prefer UK terms: GP, NHS 111, 999, A&E, pharmacist, urgent care.
